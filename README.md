# QingXiang
面向高校大学生群体的本地生活平台，整合校园周边餐饮、娱乐等商家资源，提供学生专属优惠、好物分享、好友互动等一站式服务。针对校园场景下"优惠活动集中、流量峰值明显"的特点，采用前后端分离架构，基于分布式会话、多级缓存技术构建的后端服务系统。

## 核心功能模块

### 1. 统一身份认证（短信验证码登录）

- 手机号格式正则校验
- 验证码与 Token 从 HttpSession 迁移至 Redis
- TTL 过期策略：验证码 5 分钟，Token 30 分钟
- 两层 Spring 拦截器：Token 刷新 + 权限校验职责分离

### 2. 活动报名引擎（库存扣减/并发控制）

- 活动发布时库存预热至 Redis：`activity:stock:{activityId}`
- 报名阶段 Redis DECR 原子预扣名额
- 扣减成功 → MySQL 事务完成订单落库
- 数据库联合唯一索引 `(user_id, activity_id)` 实现一人一单约束
- Spring `@Transactional` 保证库存扣减与订单创建原子性

### 3. 多级缓存策略

| 问题 | 方案 | 实现 |
|------|------|------|
| 缓存穿透 | 空值缓存 | 查询不存在数据时缓存空字符串，TTL较短 |
| 缓存击穿 | 逻辑过期时间 | expireTime判断是否过期，过期则重建缓存 |
| 缓存雪崩 | 随机过期时间 | 基础 TTL + 1-5分钟随机偏移，打散失效点 |
| 缓存一致性 | Cache Aside | 先更新数据库，再删除缓存 |

## 性能压测

### 测试环境（仅供参考）

| 组件 | 配置 |
|------|------|
| CPU | Intel i5-12400 |
| 内存 | 16GB DDR4 |
| SpringBoot | 内置 Tomcat，默认线程池 200 |
| Redis | 本地 127.0.0.1:6379 |
| MySQL | 本地 127.0.0.1:3306 |
| JVM | 默认参数 -Xms512m -Xmx512m |

### 测试工具

- Apache JMeter 5.6.3
- 线程组：100 线程，Ramp-up 10s，循环 100 次（共 10000 请求）
